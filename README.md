# Winter PEP 🐍

A collection of Python projects and learning materials developed during the Winter PEP (Practical Experience Program). This repository showcases a journey through various Python concepts, web frameworks, and data science tools.

## 📋 About

This repository contains code, projects, and experiments created as part of a structured learning program. It demonstrates progressive skill development across multiple Python domains, from fundamental algorithms to web development with FastAPI and Django, and data analysis with Jupyter Notebooks.

## ⚙️ How to Use

1.  **Clone the repository**
    ```bash
    git clone https://github.com/iamrajvardhanmall/Winter-pep.git
    cd Winter-pep
    ```

2.  **Navigate to a specific project folder** (e.g., `cd FastAPI`).

3.  **Set up a virtual environment** (recommended)
    ```bash
    python -m venv venv
    source venv/bin/activate  # On Windows use `venv\Scripts\activate`
    ```

4.  **Install dependencies** (if a `requirements.txt` file is present in the project subfolder).

5.  **Run the Python scripts or start the web servers** as per the instructions within each project's own README or comments.
